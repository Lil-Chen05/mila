# Historical experiments

This directory preserves exploratory work that preceded the final COMP 400
study. These artifacts remain available for provenance and context, but they
are not the source of the results reported in the final paper.

- `pilots/20q-200q/` contains the early greedy MMLU checkpoint experiments.
- `warmups/trivia/` contains the initial TriviaQA cluster warm-up.

The archived jobs and scripts are frozen snapshots. Do not treat them as the
current pipeline or run them on a login node. The maintained Part 1 protocol,
implementation, and operational history remain under `docs/part1/`,
`scripts/`, `jobs/`, `tests/`, `configs/`, `schemas/`, and `manifests/`.
